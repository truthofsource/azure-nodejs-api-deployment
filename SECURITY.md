# Security boundary

The sample includes only the actual public health handler. It contains no employee data, production settings, Entra IDs, connection strings, host keys or private templates. Health is not business-route authorization. Default Azure Functions v4 SDK test mode outside the host is expected.

The packaging helper has no Azure client/publisher. Its public commissioning fixture permits only a disabled health registration. The actual Flex source is parameterized and defaults Disabled. Real storage grants, environment settings, private routes and publication/activation remain separate reviewed operations.

The workflow is manual-only, read-only to GitHub and cannot publish to Azure. It does not upload artifacts. Installed dependencies, dist, local settings, runtime package outputs and state/plans remain excluded from Git. Never copy a real .env or local.settings.json into a release archive.
